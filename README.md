# BecsBot

BecsBot is a full-page Jupiter market terminal with a separate paper wallet and a manually confirmed live sell desk. **Automatic live buying is disabled.** The terminal reads Jupiter Tokens V2 top trending, top traded, and top organic score lists at 5-minute and 1-hour intervals, plus recently created pools. Search looks up any token by name, symbol, or mint through Tokens V2. Categories are refreshed every five minutes; a failed category keeps its last snapshot and shows a delay indicator.

The radar shows Jupiter's token metadata, liquidity, market cap, holder count, organic score, rank, volume, and price change where available. A missing number is displayed as unavailable. A suspicious token flagged through `audit.isSus` is labeled and cannot be paper bought. Verification and organic score are informational, not guarantees of safety. The rightmost mini chart is a price trail collected by this browser while it is open, not exchange history. On phones, swipe the radar table sideways and use the bottom navigation to switch full-height panels. Search, sorting, filters, text size, and rows per page are adjustable.

Paper trading starts with a simulated SOL balance. The default paper buy is $1 worth of SOL, with editable cash, reserve, estimated network fee, impact, and token filters. Manual paper buys work for priced Jupiter tokens; the auto paper button buys passing 5-minute trending tokens once while this browser tab is open. Auto paper resets to off when the page is reopened. Holds, the buy-once list, and activity live in this browser's local storage, so clearing site data or switching phones loses them. No paper order reaches the chain. Paper entry estimates use Tokens V2's `usdPrice`; held positions refresh through Jupiter Price V3 in batches of at most 50. Jupiter omits tokens without a reliable V3 price. An unavailable mark is labeled stale, and a paper sale requires a fresh V3 mark. Paper P/L using an older mark is only indicative.

The real wallet panel lists the configured wallet's Token and Token-2022 balances. Manual sell buttons quote with Jupiter Swap V2, require an explicit confirmation, recheck the balance and quote, and then sign only when `MANUAL_SELL_ENABLED=true` and `SOLANA_PRIVATE_KEY` derives the configured wallet. The sale does not close the receiving token account. Slippage is adjustable. There is no live buy route in this service.

Set `HELIUS_RPC_URL` and `JUPITER_API_KEY` as Railway service variables. Keep credentials out of source control and chat. The dashboard uses a six-digit BecsBot passcode with an iPhone-style keypad. Initial setup requires a private, expiring one-time link using `DASHBOARD_SETUP_TOKEN` and `DASHBOARD_SETUP_EXPIRES`. The chosen passcode is stored only as a salted scrypt hash under `DATA_DIR`; mount a persistent volume there. The browser gets a Secure, HttpOnly, SameSite=Strict session cookie valid for 12 hours; deployment restarts require another login. Five attempts from an IP trigger a five-minute cooldown; a shared cap also limits concurrent attempts. Change the passcode or lock the terminal from Settings. Changing it invalidates all earlier sessions. The old dashboard key is no longer accepted by API routes. The public wallet is configured in `src/basket.js`. Jupiter calls from market scans, search, and paper price updates share a queue spaced at least 2.2 seconds apart, with a bounded retry on HTTP 429 using Jupiter's rate-limit reset header. The Free plan's 1 RPS limit should be enough for normal use. The $25/month Developer tier is optional if measured usage later requires more throughput. Swap quotes from the separate manual sell path can still meet a rate limit during a crowded scan; retry after the limit clears. `npm test` runs the local checks.

Railway mounts the `becsbot-data` volume at `/app/data`, with `DATA_DIR=/app/data`, so the passcode and paused scan state survive deployments. Paper wallet state is still local to the browser. `/health` exposes category status publicly. Market APIs, holdings, and manual sell routes require an authenticated session.
